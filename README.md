# VaultX

A local-first password manager built with React, TypeScript, the Web Crypto API, and IndexedDB.

Your passwords never leave your device. The vault is encrypted in your browser before it is written to local storage.

## Features

- 🔐 Master-password protected vault
- 🔒 AES-GCM authenticated encryption
- 💾 Local IndexedDB storage
- 🎲 Cryptographically secure password generator
- 🔎 Vault search
- 📁 Categories
- ⭐ Favorites
- 📋 Secure clipboard handling with best-effort auto-clear
- ⏱️ Automatic vault locking
- 📦 Encrypted export/import
- 🛡️ Password security analysis (in-memory only)
- 📱 Responsive UI
